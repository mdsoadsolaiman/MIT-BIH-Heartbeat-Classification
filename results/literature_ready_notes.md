# Literature-ready notes

de Chazal, P., O'Dwyer, M., & Reilly, R. B. (2004). *Automatic classification of heartbeats using ECG morphology and heartbeat interval features*. **IEEE Transactions on Biomedical Engineering, 51**(7), 1196–1206. https://doi.org/10.1109/TBME.2004.827359

This primary study uses the AAMI-style heartbeat groups and a 44-record inter-patient MIT-BIH design. It is suitable background for discussing patient-independent heartbeat classification and the historically difficult minority supraventricular ectopic category; it does not by itself prove the cause of this repository's S errors.

Moody, G. B., & Mark, R. G. *MIT-BIH Arrhythmia Database*, version 1.0.0. PhysioNet. https://physionet.org/content/mitdb/1.0.0/; DOI: https://doi.org/10.13026/C2F305

The official database directory states that records numbered 100–124, with gaps, are the 23 randomly selected records, while records 200–234, with gaps, are the 25 arrhythmia-enriched records. This explicit documentation supports `sampling_group_split_summary.csv`; membership was not inferred from numbering without a source.
