# License Recommendation

No software license has been selected automatically. Before publishing, choose a license that matches how you want others to use the code and original documentation.

## Common Choices

- **MIT License** — short and permissive. It allows reuse, modification, and redistribution with preservation of the copyright and license notice. This is often suitable for a portfolio project intended to be easy to reuse.
- **Apache License 2.0** — permissive like MIT, with an explicit patent grant and more detailed terms. It may be preferable when patent language and formal contribution terms matter.

If you do not want to grant reuse rights yet, do not add an open-source license; public visibility alone does not make the repository open source. A license can be added later after confirming university assessment rules and ownership expectations.
